Visual substitution rules for instant orthographic normalization without rote learning.

Master these core component rules to immediately unlock hundreds of characters:

3. Dangerous Traps: One-to-Many Contextual Merges
Store these as word units rather than attempting mechanical character swaps:
发 → 發 (Emit/Develop) vs 髮 (Hair)
发展 → 發展  |  发现 → 發現  |  头发 → 頭髮
后 → 後 (Behind/Later) vs 后 (Empress/Queen)
后来 → 後來  |  以后 → 以後  |  皇后 → 皇后
复 → 復 (Return/Restore) vs 複 (Complex/Duplicate)
恢复 → 恢復  |  回复 → 回覆  |  复杂 → 複雜  |  复习 → 複習
台 → 臺 (Platform/Taiwan) vs 台 (Stage/Desk) vs 颱 (Typhoon)
台湾 → 臺灣  |  舞台 → 舞臺  |  台北 → 臺北  |  台风 → 颱風
只 → 只 (Only) vs 隻 (Measure word for animals)
只有 → 只有  |  一只猫 → 一隻貓
4. Optimal Mental Processing Hierarchy
Level 1: Is it unchanged? (e.g., 我今天很忙 → 我今天很忙)
Level 2: Recognize obvious radical substitution (e.g., 学生 → 學生)
Level 3: Recognize familiar whole-character pair (e.g., 时间 → 時間)
Level 4: Check for context-dependent ambiguous character (e.g., 发 → check meaning: 發展 vs 頭髮)
